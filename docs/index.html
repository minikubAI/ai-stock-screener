ロジック構築フェーズ

なぜ始めたのか

きっかけは単純な疑問でした。「AIに株を選ばせたら、人間より上手くいくのか？」

投資の世界には、プロのファンドマネージャーでもインデックスに勝てないという有名な話があります。 感情に左右され、ニュースに振り回され、高値掴みして安値で売る。人間が投資で負ける原因のほとんどは「メンタル」です。

じゃあ、感情を持たないAIに任せたらどうなるか。決算データを自動で読み、ニュースのトーンを数値化し、 条件に合致した銘柄だけを機械的に買い、損切りラインに達したら躊躇なく売る。 そんなシステムをゼロから作ってみることにしました。

資金は最小限。ミニ株なら1株＝数百円から買えるので、元手1,000円でも始められます。 大事なのは金額じゃなく、ロジックが正しいかどうか。それを検証するための実験です。
