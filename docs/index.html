スクリーニング手法

5つの分析レイヤー + Core/Satellite分類で総合判定

1

財務スクリーニング（25%）

PER・PBR・ROE・配当利回り・自己資本比率・時価総額で絞り込み。割安かつ財務健全な企業を抽出。東京プロマーケット銘柄は除外。

● 稼働中
2

5年トレンド分析（25%）

売上高・営業利益・ROE・EPSの過去5年推移を回帰分析。改善中の企業と悪化中の企業を定量的に区別。連続増収増益を加点。

● 稼働中
3

バリュエーションギャップ分析（20%）

業績の改善度と株価指標（PER/PBR）の変化のズレを検出。「業績は良くなっているのに株価が追いついていない銘柄」を高評価。市場に見落とされている銘柄を発掘する独自ロジック。

● 稼働中
4

ニュース・センチメント分析（15%）

適時開示（決算短信・業績修正）を自動取得し、テキストからポジティブ/ネガティブをスコア化。上方修正・増配は加点、下方修正・不祥事は即減点。

● 稼働中
5

マクロ環境判定（15%）

日経平均（200日移動平均との乖離）、VIX、USD/JPYから市場全体の「買い時 / 通常 / 様子見 / 停止」を自動判定。

● 稼働中
+

業界超過成長率ボーナス

企業の成長率を同業種平均と比較。業界が停滞している中で成長している企業を追加加点。「追い風に乗っているだけ」の企業と「自力で勝っている」企業を区別。
